# The Cache Hit That Served the Wrong Language

Fictional incident: the origin renders the requested language, yet a warm cache returns another language. Repair `select_variant` in `variant_cache.py`. Run `python monitor.py` and `python -m unittest discover -s tests -v`. Starter failures are intentional.

## Exact exercise API
`capture_entry(method, url, request_headers, body, *, vary="", cache_control="public", stored_at=0, max_age=60)` is supplied infrastructure. It returns a detached record, or None for non-GET, `Vary: *` (including mixed lists), or no-store. Do not insert None records into the cache.

`select_variant(entries, method, url, request_headers, now)` returns a detached complete record or None. Validate ALL records even when a previous record matches. A malformed record anywhere raises ValueError. Entries must be exactly the canonical dictionaries created by capture_entry, with no extra fields. Select only exact URL keys and uppercase GET. Header names match case-insensitively; values are opaque, case-sensitive strings, including whitespace. An absent header is different from an empty one. Compare only names named by each stored entry's Vary list. Empty Vary permits any request headers. Freshness requires stored_at <= now < stored_at + max_age. Zero lifetime is never fresh. Among eligible matches choose greatest stored_at, then last input index. Do not mutate inputs or share mutable return state.

## Validation
Headers are dictionaries of HTTP-token string names to strings without CR/LF. Reject case-colliding names, even if values agree. Method is a nonempty token (other valid methods produce a miss); URL is a nonempty opaque string without CR/LF, not normalized. Vary is empty or a comma-separated token list; trim space/tab around tokens, lowercase, deduplicate and sort. Reject empty components, whitespace-only metadata and non-token names. Cache-Control accepts ONLY empty or comma-separated `public` and `no-store` tokens, case-insensitive; any other directive is invalid. max_age is separate trusted policy metadata, NOT parsed from HTTP Cache-Control. Body must be str. Times/lifetimes must be finite nonnegative int/float, not bool. NaN/infinity and integers outside finite float range are rejected. The sum stored_at + max_age must also be finite; overflowing expiry is rejected. Records with malformed structure, noncanonical header names or Vary lists are rejected. All invalid inputs raise ValueError.

## Scope and limits
This is an offline teaching model, NOT an RFC-compliant HTTP cache, proxy or security boundary. No network, auth, cookies, conditional requests, ETags, status codes, Age/Date correction, revalidation, eviction, memory bound, URL normalization, quoted directives, header-combination rules, concurrency or real HTTP parser. Vary values are supplied policy metadata. Production reuse has many additional constraints. CI is supplied but not executed on GitHub. Hosted GetIn integration, bot execution and gates are unverified. Reference implementation and audit evidence are outside the learner repository in the delivery package.
